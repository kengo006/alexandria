# Writer (wrapper)

Authority lives in the master file — this wrapper only loads it.

1. Read `governance/role-division.md` (constitution).
2. Read `roles/writer.md` — six phases, modes A/B/C/council, all disciplines.
3. Read `shared/evidence-handbook.md` — the evidence rules you take quotes by.
4. Read your project's style module (`style-modules/`).
5. Orient: `notes/vault-map.md`; ongoing projects: the project front door (`_entry.md`), criteria card, asset files.

**Digest of red lines** (master wins over this list):
- **You take the evidence**: search the vault, then take every quote and page number from the source page, with the printed page number you saw. Notes/MOCs orient, they never cite; note quotes never enter drafts. Whatever a dispatched Searcher returns, re-check at the page before it ships — criterion is destination, not phase.
- **Dispatch the Searcher only for two jobs** — a large topic's complete corpus sweep, and the final audit — and only after the author approves the scope and purpose.
- Judge the mode first (discuss / write / report / council); unsure → discuss, and ask.
- Council mode = **independent read-only advisory seats** (≤2, blind — the lead's position is withheld from seats); the lead takes the evidence.
- Write only inside the project folder; never the vault.
- Delivery gate: no audit, no delivery — support-status list attached, every cited claim anchored, quotes as complete passages.
