# Examples

> 🔴 **Everything in these files is fabricated.** Every work, author, quotation and page number below is invented — `Doe (2011)`, `Roe (1998)`, `Poe (2005)` and `Ives (2014)` are placeholders, not publications, and the sentences attributed to them were written for these files. **Copy the shape; never copy the content.** The longer version of why this warning comes before the table is at the bottom of this page.

Three worked outputs, so you can see what the roles actually produce before deciding whether the discipline is worth adopting.

| File | What it shows |
|---|---|
| [`searcher-discovery-report.md`](searcher-discovery-report.md) | What comes back when the Writer spawns the Searcher for evidence: verbatim quotes at real pages, four-layer verification marks, the mandatory opposing-positions section, and honest gaps |
| [`critic-review.md`](critic-review.md) | A blind first-round review: standards pre-committed before the draft was read, located criticisms, the sections that are mandatory even when empty |

Read them in that order and you have seen the pipeline end to end.

## 🔴 Everything here is fabricated, on purpose

*(The short form of this is at the top of the page, above the table — because a reader who arrives, scans the table and clicks through has already left this section unread.)*

This matters more here than in most repositories, because the system these examples demonstrate exists to stop exactly one thing: **text that looks like a citation and is not one.** A worked example of a citation pipeline is the last place that should ship a plausible-looking fake reference into someone's notes.

⚠ **So: do not copy a quotation out of these files.** Copy the *shape* — the fields, the marks, the sections that must be written even when the answer is "none". The content is scaffolding.

📌 The underlying research domain is also invented (a small literature on memorial practice), chosen because it is close enough to real humanities work to be illustrative and far enough from any actual bibliography to be unmistakable.

---

## What to look for

- **Where the page numbers come from.** Every ✅ in these files traces to a rendered page image whose *printed* number was read off and reported. That report is the credential: an agent that never opened the page cannot produce it.
- **The sections that are filled in with "none".** Opposing positions, "no criticism", negative universals — each is mandatory. A blank means *nothing found* and *did not look* at the same time, and the reader cannot tell which.
- **What failure looks like.** The audit's ❌ rows and the Searcher's "pending verification" section are the point of the whole design. A pipeline whose examples are all green is a pipeline whose examples were curated.
